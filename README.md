#Unemployment Analysis in India During COVID-19

Developed a comprehensive data analysis and visualization project to study unemployment trends in India, with a focus on the impact of COVID-19. The project includes data preprocessing, time-series simulation (if CSV unavailable), and visualizations comparing overall, urban/rural, and male/female unemployment rates. Key features include:

Simulated time-series data (Jan 2018–Dec 2024) with COVID-specific unemployment spikes.

Dynamic visualizations showing the impact period (Mar 2020–Jun 2021).

Comparative analysis between demographics (urban vs rural, male vs female).

Statistical summaries for pre-COVID, during COVID, and post-COVID periods.

Modular structure supports real CSV data integration.

This project provides actionable insights into how different segments of the population were affected by economic disruptions due to the pandemic.
